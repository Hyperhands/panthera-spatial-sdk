# 实机前验证

本页记录 C、D、E、G 的本机验收条件和重现入口。模型和时延数据对应 x86_64 Release 构建，运动与断链测试均通过回环 UDP 完成。

## 模型与碰撞

左右臂各使用 128 组关节角，对编译后的 CasADi C 函数与 Pinocchio 独立计算结果取最大绝对误差。比较范围包含连杆和 TCP 的世界坐标变换、TCP 雅可比及六轴重力矩，手指固定在中立位。左右侧分别为 3.55e-15 和 3.11e-15。生成步骤如下。

```sh
python -m pip install -r tools/codegen/requirements.txt
python tools/codegen/model.py
python tools/codegen/capsules.py
```

32 个胶囊组成 392 个启用配对，来自原始 SRDF。拟合时按完整三角形分区。每个手的掌、四指和拇指各有一个包络，关节网格覆盖主动轴全行程并截断超出 URDF 限位的 mimic 角度。半径额外包含各祖先关节从最近采样点移到网格单元内任意姿态的最大位移和。

同臂折叠时外包胶囊会先于实际网格相交。近距对另存一组随连杆运动的分隔平面，并用定向盒包住另一侧的对应三角形。对凹形网格递归拆分完整三角形，直到每个子对都有正的分隔证明。运行时保留胶囊硬停阈值，并取胶囊距离与分隔证明中较大的间隙下界执行物理间隙检查。手部证明包含连续扫掠余量。具体胶囊、逐对阈值和三姿态报告见[生成数据](../generated/model/capsules.json)。

| 姿态 | 最小原始胶囊距离 mm | 最小臂间距离 mm | 最小可证明间隙 mm |
| --- | ---: | ---: | ---: |
| zero | -26.071 | 212.872 | 0.084 |
| ready | -18.656 | 212.872 | 6.523 |
| home_waypoint | -18.456 | 213.609 | 1.749 |

零位的 0.084 mm 是名义装配模型的几何下界。实际装配误差和实测手行程属于 WP-H。回归测试覆盖两臂从零位同时抬升 J2、J3 各 5° 的过程。

## 控制器与回环

`motion_qp` 验证滞后逼近上限时的下一参考、16 槽之外的违约约束换入重解。`control_law` 验证双臂对向接近、随机目标全对复核、零位抬臂和连续失败保持。对向测试的最小臂间距离为 20.0 mm。p99 统计每周期所有 HPIPM 求解调用的累计时间，求解前后的运动学、碰撞计算和 UDP 收发另计。运行下列命令会打印当前机器的用时。

```sh
ctest --test-dir build/host -V -R 'motion_qp|control_law|sim_controller'
```

`sim_controller` 在两板的正常接管入口分别执行限速限加的直线和位置阶跃，并从收到的关节遥测重算稳态 TCP 误差。两种场景均要求两侧位置误差小于 2 mm、姿态误差小于 1°。测试还在运动期间注入单向断链、板端故障、单板重启和测量滞后，检查双侧冻结和板端实际收到的软停操作。重启测试显式重新使能后检查旧目标没有被重放。专家模式单独检查原始 MIT 指令的线格式。

## 固件

左右板各在两个独立输出目录中构建后逐字节比较。每个镜像为 158476 字节，保留启动回零、对端链路和主机看门狗。原生套件运行导入的 21 个 C 测试源，涵盖主机接管、软停、CAN、手部、双板回零及保留的遥操逻辑。构建步骤和校验值见[固件说明](../firmware/README.md)与[镜像摘要](../firmware/images/SHA256SUMS)。
